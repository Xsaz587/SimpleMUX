# SimpleMUX

Два файла, которые превращают Termux на телефоне в удобный Linux с красивым терминалом и рабочим столом.

| Файл | Для чего |
|------|----------|
| `1t-setup.sh` | **Установщик.** Меню, где галочками выбираешь, что поставить: программы, языки программирования, рабочий стол, эмуляторы. Умеет чинить ошибки |
| `visual-termux.sh` | **Кастомизация.** Делает терминал красивым и удобным: цветное приглашение, меню для перемещения по папкам, полоса загрузки при установке |

Можно использовать оба, а можно только один. Они не зависят друг от друга.

---

## Что нужно заранее

1. Телефон на Android
2. Приложение **Termux**, лучше с [F-Droid](https://f-droid.org/packages/com.termux/) или [GitHub](https://github.com/termux/termux-app/releases). Версия из Google Play устарела и работает плохо
3. Интернет
4. Скачанные файлы `1t-setup.sh` и `visual-termux.sh`

Для рабочего стола (по желанию) нужно ещё приложение **Termux:X11**. Установщик сам подскажет, где его взять.

---

## Шаг 0. Положи файлы туда, где их видит Termux

Открой Termux и выполни:

```bash
termux-setup-storage
```

Появится запрос на доступ к файлам, нажми «Разрешить». Теперь твои «Загрузки» видны в Termux как `~/storage/downloads`.

Скопируй файлы в домашнюю папку:

```bash
cp ~/storage/downloads/1t-setup.sh ~/storage/downloads/visual-termux.sh ~
```

## Файл 1. `visual-termux.sh`: красивый терминал

### Как запустить

```bash
bash visual-termux.sh
```

Всё. Терминал сразу изменится. Перезапускать Termux не нужно.

> ⚠️ **Сделай копию перед запуском:** `cp ~/.bashrc ~/.bashrc.bak`
> Скрипт переписывает хвост файла `~/.bashrc`. Если ты сам что-то туда добавлял, это может пропасть.

### Что ты получишь

**1. Красивое приглашение** вместо обычного `$`: цветной путь и стрелка.

**2. Приветствие при открытии:** заряд батареи, свободное место, время.

**3. Меню папок.** Просто напиши `cd` без ничего, и откроется список папок:

| Клавиша | Что делает |
|---------|-----------|
| ↑ ↓ | выбрать папку |
| Enter или → | зайти в папку |
| ← | выйти на уровень выше |
| G | остаться в выбранной папке и закрыть меню |
| Esc или Q | закрыть меню |

Обычный `cd папка` работает как раньше.

**4. Меню запуска.** Напиши `cd-run`: покажет папки и файлы `.sh`, `.py`, `.js`.

| Клавиша | Что делает |
|---------|-----------|
| ↑ ↓ | выбрать |
| Enter или → | открыть папку |
| **R** | **запустить** выбранный файл |
| **E** | **редактировать** файл в nano |
| ← | назад |
| Q или Esc | выход |

**5. Полоса загрузки** при `pkg install`, `apt install` и `pkg upgrade`. Показывает прогресс, а в конце: успешно или какая ошибка и что делать. Если установка шла дольше 10 секунд, придёт уведомление (нужно приложение Termux:API).

**6. Короткие команды:**

| Команда | Что делает |
|---------|-----------|
| `up` | обновить всё |
| `dl` | перейти в «Загрузки» |
| `ll` | список файлов с подробностями |
| `..` | на папку выше |
| `cls` | очистить экран |

### Как вернуть как было

Восстанови копию: `cp ~/.bashrc.bak ~/.bashrc`, затем перезапусти Termux.

## Файл 2. `1t-setup.sh`: установщик

### Как запустить

```bash
bash 1t-setup.sh
```

Откроется меню. Управление простое: **пишешь цифру или букву и жмёшь Enter**.

### Главное меню

```
=== 1t-setup ===
 1) Видео и графика        2/6
 2) Звук                   0/5
 3) Оболочки (shell)       1/7
 ...
 r) ПОЧИНКА    g) запустить рабочий стол   f) чёрные рамки
 p) мощность   s) инфо о системе   w) Wi-Fi   v) ISO/EXE/APK
 u) обновить пакеты   q) выход
```

Цифры справа (`2/6`) показывают, сколько из категории уже установлено.

### Как поставить программу

1. Выбери категорию цифрой, например `8` (Пакеты и сервисы)
2. Увидишь список. `[✓]` значит уже стоит, `[ ]` значит нет
3. Напиши номера через пробел, например `1 3 4`, и Enter. Или `a`, чтобы поставить всё недостающее
4. `0` возвращает назад

Скрипт сам подключит нужные репозитории, проверит, что пакет существует, и подберёт замену, если нет.

### Что можно поставить

| Категория | Что внутри |
|-----------|-----------|
| Видео и графика | Mesa, Vulkan, FFmpeg, mpv |
| Звук | PulseAudio, SoX, espeak |
| Оболочки | zsh, Oh My Zsh, fish, tmux, starship |
| Графические среды | XFCE, KDE Plasma, MATE |
| Пакеты для XFCE | файловый менеджер, меню, скриншоты |
| Композитор и темы | picom, тема Arc, иконки Papirus, шрифты |
| Языки программирования | Python, Rust, Node.js, PHP, Ruby, C/C++, C#, Go, Java |
| Пакеты и сервисы | git, curl, SSH-сервер, proot-distro, htop, nano |
| Виртуализация | QEMU, box64, Wine, Mobox, adb |
| Приложения | Firefox, Chromium, Telegram, Minecraft, VLC |
| Ввод и сеть | nmap, Wi-Fi сканер, джойстик |

### Как запустить рабочий стол (как на компьютере)

1. Поставь **Termux-X11** и одну среду (**XFCE** самая лёгкая) из категории «Графические среды»
2. Поставь приложение **Termux:X11** на телефон (скрипт откроет страницу загрузки)
3. В главном меню нажми `g`
4. Выбери среду и режим графики:
   - `software` работает везде, но медленнее
   - `virgl` быстрее на многих телефонах
   - `turnip+zink` только для телефонов с Adreno (Snapdragon)
5. Переключись в приложение Termux:X11, там появится рабочий стол

Не знаешь, что выбрать? Нажми `p` в главном меню: скрипт проверит телефон и подскажет.

### Остальные кнопки главного меню

| Клавиша | Что делает |
|---------|-----------|
| `p` | проверка мощности телефона и рекомендация |
| `s` | информация о телефоне |
| `w` | список Wi-Fi сетей рядом |
| `f` | убрать чёрные рамки у меню на рабочем столе |
| `v` | запуск ISO (QEMU), .exe (Wine/Mobox), установка .apk |
| `u` | обновить все пакеты |
| `q` | выйти |

### 🔧 Починка (кнопка `r`)

Если что-то сломалось, сначала зайди сюда.

| Пункт | Когда нужен |
|-------|-------------|
| 1. Пакеты | не ставятся программы, ошибки `dpkg` / `apt`. Скрипт сам прогонит починку по шагам |
| 2. Звук | нет звука. Играет тон, спрашивает «слышно?», пробует способы по очереди |
| 3. Два динамика | звук идёт только из одного динамика |
| 4. Другая проблема | описываешь словами, получаешь отчёт |
| 5. Последний отчёт | показать прошлый отчёт |
| 6. Сбросить звук | откатить настройки звука |

**Если автопочинка не помогла**, скрипт соберёт **готовый текст для ИИ** (что сломано, что уже пробовали, данные о телефоне, логи). Скопируй его (скрипт предложит положить в буфер обмена) и отправь в ChatGPT, Claude и т. д. с просьбой помочь.

## Частые вопросы

**Ничего не происходит / «No such file».** Проверь, что ты в той папке, где лежит файл: `ls`. Файл должен быть в списке.

**«Нет такого пакета».** Попробуй в `1t-setup` пункт `r` → `1`, он обновит списки и починит репозитории.

**Нет интернета при установке.** Проверь соединение и VPN. Починка предложит сменить зеркало.

**Рабочий стол тормозит.** Выбери XFCE и графику `virgl` или `software`, выключи композитор (кнопка `f`).

**Хочу удалить всё это.** Настройки установщика: `rm -rf ~/.1t-setup`. Оформление терминала: восстанови `~/.bashrc.bak`.

## Где скрипты хранят свои данные

| Путь | Что там |
|------|---------|
| `~/.bashrc` | настройки оформления |
| `~/.1t-setup/` | конфиг, логи, список неудачных пакетов, последний отчёт |
| `~/.xsaz_last_install.log` | лог последней установки |
| `~/vm/` | диск для виртуальной машины |

---

## Важно знать

- Всё работает **без root**
- Графика, QEMU и Wine на телефоне работают по-разному, зависит от процессора и видеочипа
- Mobox скачивается с GitHub (`olegos2/mobox`), посмотри его содержимое перед установкой
